POKEKYOTO - VUURVLIEGJES EN DEBUGMENU

Deze update is voor de laatste Pokekyoto_Lantern_Fix-installatie.
De extra box-grenscontrole mag al aanwezig zijn; de installer herkent beide versies.

1. Commit eerst je bestaande wijzigingen, inclusief de lantaarn-update.
   Pushen hoeft nog niet. Voeg de uitgepakte installatiemappen niet toe aan de commit.
   Als GitHub Desktop nog blijft verversen, kun je deze eerdere update vanuit Ubuntu
   committen met onderstaande regels. 'git add -u' neemt alleen al gevolgde bestanden
   mee; de nieuwe bestanden die de vorige installer al heeft gestaged blijven gestaged.

   cd ~/PokemonDev/pokekyoto
   git add -u
   git commit -m "Lantaarnverlichting, menu fixes en box-grenscontrole"

2. Pak de ZIP uit en zet de HELE map Pokekyoto_Fireflies_Debug in je pokekyoto-map.

3. Open Ubuntu en voer uit:

   cd ~/PokemonDev/pokekyoto
   bash Pokekyoto_Fireflies_Debug/install_fireflies_debug.sh

4. Wacht tot de build klaar is. Open daarna pokeemerald.gba in mGBA.
   Gebruik je gewone save via Continue.

BEDIENING
- Houd B vast en druk op Start voor het debugmenu. B sluit het menu/submenu.
- Via Utilities > Set weather kun je 11 (FIREFLIES) kiezen om het effect te testen.
- Voor een permanente mapinstelling kies je WEATHER_SHADE in Porymap.
- Bestaande maps met Shade krijgen nu automatisch vuurvliegjes.

BRON
De opgegeven PokePeach-GitHub was niet bereikbaar (404/authenticatie).
Daarom is de vuurvliegjes-code uit je eerdere pokepeach.zip gebruikt.
De oorspronkelijke sprites en bewegings-/lichtcirkelcode zijn overgenomen.
Kyoto's bestaande debugmenu is aangezet met dezelfde B + Start-combinatie.

Het testfilmpje gebruikt een testmap en testklok. Die testaanpassingen,
test-Pokemon en boot-shortcut staan niet in deze installatie.
De README_EN.md is de Engelse uitleg voor je developer.

Bij een fout: stuur de laatste melding. Forceer geen patch.
Commit na een geslaagde installatie de wijzigingen op de nieuwe branch.
